# STM32_241_project_HCMUT

## Tiên quyết: Dự án được thực thi trên mạch thật và không có mô phỏng, kết quả lưu được đã được trình bày trong Report
  
## Commands
- `build`: để compile tất cả các file code
- `upload`: nạp chương trình vào thiết bị 

## Cấu trúc của BTL:
```
 ┣ 📂.settings      
 ┣ 📂Core           # Các các file source và include.
 ┣ 📂Debug          # Một vài output mẫu.
 ┣ 📂Drivers
 ┣ 📂.cproject
 ┣ 📂.mxproject   
 ┣ 📂.project       # File code.
 ┣ 📂F103RB.ioc     # Chứa file .ioc cài đặt các pins của STM32.
 ┣ 📜Assignment     # Report của sản phẩm.
```
